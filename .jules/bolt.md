## 2023-11-09 - Avoid Synchronous Blocking Calls in Home Assistant Components
**Learning:** Using synchronous `time.sleep()` in Home Assistant custom components (like in entity methods `set_cover_tilt_position`) blocks the executor thread and can cause significant performance issues across the entire system. Home Assistant favors asynchronous implementations for these operations.
**Action:** Always replace blocking `time.sleep()` with `await asyncio.sleep()` and convert the method to an asynchronous handler by prefixing it with `async_` (e.g., `async_set_cover_tilt_position`), which is natively supported and detected by Home Assistant entity base classes. When updating tests for such components, ensure an event loop is properly initialized if `asyncio.get_event_loop()` fails.
